# Next steps and course links

## Advanced Cognitive Neuroscience

Continue practising:

- multidimensional NumPy arrays;
- axes and aggregation;
- participant and group-level dimensions;
- paths and file discovery;
- Matplotlib's object-oriented API;
- reading methods and attributes on unfamiliar objects.

## Natural Language Processing

The current course book includes environments, dependency management, `pathlib`, scripts, GitHub, UCloud, and notebooks using a modern NLP stack.

- [NLP at Cognitive Science](https://github.com/MinaAlmasi/nlp-at-cogsci)
- Libraries include pandas, NumPy, scikit-learn, spaCy, PyTorch, Transformers, and sentence-transformers.

## Data Science, Prediction and Forecasting

The course progresses through statistical learning, regression, classification, resampling, regularisation, nonlinear models, trees, SVMs, and deep learning.

- [An Introduction to Statistical Learning](https://www.statlearning.com/)
- Focus first on samples/features, clean train/test separation, pipelines, and evaluation.

## Advanced Cognitive Modeling

- [AU Advanced Cognitive Modeling materials](https://github.com/LegrandNico/CognitiveModeling)
- Continue with NumPy, SciPy, Matplotlib, Bayesian modelling, simulations, and reinforcement-learning concepts.

## A four-question reading strategy

When opening future course code, ask:

1. Which objects exist?
2. What are their types and shapes?
3. Which transformations occur?
4. What does each transformation mean scientifically?
