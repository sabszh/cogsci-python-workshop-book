# Student notebooks

Start with `00_python_warmup.ipynb`, then work through the numbered notebooks in order:

1. `00_python_warmup.ipynb`
2. `01_lexical_decision_pandas.ipynb`
3. `02_eeg_arrays.ipynb`
4. `03_model_workflow.ipynb`
5. `04_nlp_text_features.ipynb`

Open the repository folder in VS Code before opening a notebook, and select the workshop Python environment as the kernel. Keep `workshop_checks.py` in this folder; the notebooks use it to provide exercise feedback.

See the [setup guide](../book/setup.md) if the environment or kernel is not ready yet.
